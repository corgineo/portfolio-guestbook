# AI 커리어 트윈: 진로 검증 과정 기록과 방명록

가천대학교 컴퓨터공학과 김희민의 개인 홈페이지입니다. 2026 아르테크네 프로젝트 "AI 커리어 트윈"의 4주 과정을 정리했습니다.

배포 주소: https://portfolio-guestbook-6fk1.onrender.com

## 무엇을 담았나

AI가 그려 준 "10년 후의 나"(1인 창업가, 디지털 마케터, 백엔드 개발자)를 공개 통계와 현직자 인터뷰, 직접 체험으로 검증하고 진로를 고른 과정입니다.

- 4주 과정과 단계별로 알게 된 것, 시행착오
- 따라 할 수 있는 빈칸 양식: AI 3종 비교 프롬프트, 트윈 인터뷰 질문, 현직자 질문지, 사실 검증표, 스코어카드
- 가중치와 점수를 넣으면 총점을 계산해 주는 스코어카드
- 방문자가 글을 남기는 방명록 (FastAPI + SQLite)

## 만든 목적

1. 창업 준비: 기획부터 제작, 테스트, 배포까지 끝까지 해 보는 연습입니다. 앞으로 창업에 사용할 홈페이지를 만들고 고객에게 홈페이지 제작을 제안하기 위한 초석입니다.
2. 경험 공유: 여러 진로 사이에서 고민하는 대학생이 이 과정을 참고해 자신의 진로를 스스로 검증해 볼 수 있도록 정리했습니다.

## 실행

Python 3.9 이상에서:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

- 포트폴리오: http://127.0.0.1:8000/
- 상태 확인: http://127.0.0.1:8000/health → `{"status":"ok"}`
- API 실행 화면: http://127.0.0.1:8000/docs
- `POST /guestbook`: `{"name":"방문자","content":"안녕하세요"}`
- `GET /guestbook`: 최신순 목록

데이터는 `id`, `name`(1~10자), `content`(1~500자), `created_at`(서버의 UTC 시각)으로 구성합니다.
앞뒤 공백을 제거하며 공백뿐인 입력은 422로 거절합니다. SQL 값은 `?` 파라미터로 전달합니다.
DB는 기본적으로 프로젝트 폴더의 `guestbook.db`이며 `GUESTBOOK_DB` 환경변수로 경로를 바꿀 수 있습니다.
DB와 가상환경은 Git에 포함하지 않습니다.

## 배포

`render.yaml`에 Render 무료 웹 서비스 설정이 있습니다. 무료 요금에서는 15분간 접속이 없으면 서버가 잠들고, SQLite 파일은 재시작·재배포·잠들 때 초기화되어 방명록 글이 사라집니다.
글을 계속 보관하려면 영구 저장소가 있는 환경에서 `GUESTBOOK_DB`를 그 경로로 설정합니다. Dockerfile은 컨테이너 빌드를 검증하지 않았습니다.
